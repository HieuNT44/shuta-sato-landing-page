# shuta-sato-landing-page

Next.js 16 + Tailwind CSS 4 landing page.

## Getting Started

Requires [Node.js](https://nodejs.org) 20.9 or later.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/getting-started/fonts) to automatically optimize and load [Geist](https://vercel.com/font).

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — run the production server
- `npm run lint` — run ESLint
